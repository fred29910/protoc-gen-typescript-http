# GitHub CI 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 为 protoc-gen-typescript-http 项目创建 3 个 GitHub Actions workflow（lint、test、release），实现自动化代码检查、测试和多平台发布。

**架构：** 参考 migra-go 的 CI 模式，创建 3 个 workflow 文件放到 `.github/workflows/` 目录。Lint 负责格式和静态检查，Test 负责单元测试和集成测试，Release 负责多平台构建和 GitHub Release。项目是纯 Go 无 C 依赖，Release 使用单 job 即可。

**技术栈：** GitHub Actions、Go 1.25.7、buf v1.69.0、mage v1.17.2、golangci-lint、goreleaser

---

## 文件结构

将要创建的文件：

| 文件 | 职责 |
|---|---|
| `.github/workflows/lint.yml` | 代码格式检查 + 静态分析 |
| `.github/workflows/test.yml` | 单元测试 + 集成测试 |
| `.github/workflows/release.yml` | 多平台构建 + GitHub Release |

## 任务

### 任务 1：创建 `.github/workflows/lint.yml`

**文件：**
- 创建：`.github/workflows/lint.yml`

- [ ] **步骤 1：创建 lint.yml**

创建文件 `.github/workflows/lint.yml`，内容如下：

```yaml
name: Lint

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.25.7'
          cache: true

      - name: Run gofmt check
        run: |
          unformatted=$(gofmt -l .)
          if [ -n "$unformatted" ]; then
            echo "The following files are not formatted:"
            echo "$unformatted"
            exit 1
          fi

      - name: Run go vet
        run: go vet ./...

      - name: golangci-lint
        uses: golangci/golangci-lint-action@v7
        with:
          version: latest
          args: --timeout=5m

      - name: Install buf
        run: go install github.com/bufbuild/buf/cmd/buf@v1.69.0

      - name: Run buf lint
        run: cd examples/proto && buf lint
```

- [ ] **步骤 2：Commit**

```bash
git add .github/workflows/lint.yml
git commit -m "ci: add lint workflow"
```

### 任务 3：创建 `.github/workflows/release.yml`

**文件：**
- 创建：`.github/workflows/release.yml`

- [ ] **步骤 1：创建 release.yml**

创建文件 `.github/workflows/release.yml`，内容如下：

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    name: Release
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.25.7'
          cache: true

      - name: Run GoReleaser
        uses: goreleaser/goreleaser-action@v6
        with:
          version: latest
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.RELEASE_TOKEN }}
```

- [ ] **步骤 2：Commit**

```bash
git add .github/workflows/release.yml
git commit -m "ci: add release workflow"
```

# Deno Fmt 替换 ESLint 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 用 `deno fmt` 替换当前使用 ESLint 的 TypeScript 生成代码格式化流程，同时保留原有的 `eslint-disable` 注释兼容插件使用者，并修改测试流程。

**架构：** 修改 Go 生成器代码注入 `deno-lint-ignore-file`；清理 ESLint 相关配置；通过修改 Makefile 及 Go 集成测试代码中注入 `deno fmt` 命令来实现强制格式化；并在 GitHub Actions 中补充安装 Deno 环境。

**技术栈：** Go, Deno, GitHub Actions, Make

### 任务 3：在集成测试中注入 Deno 格式化

**文件：**
- 修改：`tests/integration/integration_test.go`

- [ ] **步骤 1：修改集成测试代码**

在 `cmd.Run()` (即 `buf generate`) 之后、`verifyClean()` 之前，追加执行 `deno fmt gen/typescript` 命令。

```go
// tests/integration/integration_test.go

// ... existing code ...
	err = cmd.Run()
	assert.NilError(t, err, "buf generate failed")
	
	// Run deno fmt on the generated code
	fmtCmd := exec.Command("deno", "fmt", "gen/typescript")
	fmtCmd.Dir = filepath.Join(absRoot, "examples", "proto")
	fmtCmd.Stdout = os.Stdout
	fmtCmd.Stderr = os.Stderr
	err = fmtCmd.Run()
	assert.NilError(t, err, "deno fmt failed")
	
	// Verify that the generated code is clean (no git diff)
	verifyClean(t, absRoot)
}
// ... existing code ...
```

- [ ] **步骤 2：更新集成测试并验证**

运行：`make integration` (这会触发失败因为生成的代码被 Deno 重新格式化后和 git 暂存不同，或者如果本地没有 Deno 环境会报错 "executable file not found")
由于集成测试预期代码一致，修改插件导致生成输出变更，所以 `git diff` 验证会失败（或者如果在步骤 4 一起进行，则一起修复 diff）。这属于预期内。

- [ ] **步骤 3：Commit**

```bash
git add tests/integration/integration_test.go
git commit -m "test: format generated code with deno fmt in integration tests"
```

### 任务 4：在 Makefile 中集成 Deno 及 CI 环境配置

**文件：**
- 修改：`Makefile`
- 修改：`.github/workflows/test.yml`

- [ ] **步骤 1：修改 Makefile 增加 Deno 格式化**

在 `generate` 阶段加上 `deno fmt`，保持开发者的本地工作流完整。

```makefile
# Makefile
# ... existing code ...
.PHONY: generate
generate: build
	cd examples/proto && PATH=$(abspath bin):$(BUF_DIR):$$PATH buf generate
	cd examples/proto && deno fmt gen/typescript
# ... existing code ...
```

- [ ] **步骤 2：更新 GitHub Actions CI 工作流**

引入 `denoland/setup-deno@v1`。

```yaml
# .github/workflows/test.yml

# ... existing code ...
    steps:
      - uses: actions/checkout@v4

      - name: Set up Go
        uses: actions/setup-go@v5
        with:
          go-version-file: 'go.mod'
          cache: true

      - name: Set up Deno
        uses: denoland/setup-deno@v1
        with:
          deno-version: v1.x

      - name: Setup buf
# ... existing code ...
```

- [ ] **步骤 3：重新生成代码解决集成测试 diff**

运行命令生成并更新 git 工作区以使测试通过。
运行：`make generate`
这应该会使用最新插件生成代码并自动执行 `deno fmt`。生成的 `examples/proto/gen/typescript` 代码格式将发生改变。

- [ ] **步骤 4：运行集成测试验证**

运行：`make integration`
预期：PASS

- [ ] **步骤 5：Commit**

```bash

git commit -m "build: integrate deno fmt and setup CI environment"
```
